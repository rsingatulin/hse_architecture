# Документ 6. Основные данные предприятия

## 1. Общая информация

В деятельности компании RetailMax используется единый набор бизнес-данных, которые создаются, изменяются и используются различными информационными системами.

Каждый объект данных имеет владельца, информационную систему-источник и системы, использующие эти данные.

В рамках проекта цифровой трансформации необходимо обеспечить единообразное использование данных всеми корпоративными приложениями.

# 3. Описание объектов данных

## D-01. Товар

### Назначение

Используется для хранения информации о товарах, реализуемых компанией.

### Основные атрибуты

- идентификатор товара;
- артикул;
- наименование;
- категория;
- производитель;
- цена;
- гарантийный срок;
- статус товара.

### Владелец данных

Коммерческий отдел.

### Основная информационная система

ERP.

### Используется в системах

- ERP
- Интернет-магазин
- POS
- WMS
- BI

# 6. Основные проблемы управления данными

В ходе анализа существующей архитектуры были выявлены следующие проблемы:

- отсутствует единая модель корпоративных данных;
- данные о клиентах могут дублироваться;
- остатки товаров обновляются с задержкой;
- отсутствуют единые правила именования объектов данных;
- отсутствует централизованное управление качеством данных;
- часть отчетов строится на устаревшей информации;
- отсутствуют формализованные владельцы данных и правила их сопровождения.

# 7. Задания студентам

На основании данного документа необходимо:

1. Определить основные бизнес-сущности выбранного процесса.
2. Построить концептуальную модель данных.
3. Определить владельцев данных и ответственных за их качество.
4. Выделить данные, используемые несколькими информационными системами.
5. Предложить меры по устранению дублирования данных.
6. Разработать модель данных для целевой архитектуры.
7. Определить требования к обмену данными между информационными системами.
