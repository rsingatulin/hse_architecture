# 11. Допущения для выполнения расчетов

При выполнении технико-экономического обоснования допускается использовать следующие предположения.

- Экономический эффект начинает проявляться со второго года эксплуатации.
- Горизонт расчета составляет 5 лет.
- Архитектурные решения внедряются поэтапно.
- Стоимость сопровождения новой архитектуры может изменяться в зависимости от выбранного решения.
- Студенты могут самостоятельно принимать обоснованные допущения, если они явно указаны в отчете.

# 12. Исходные данные для оценки рисков

При анализе рисков необходимо учитывать следующие вводные.

| Фактор | Описание |
|---------|----------|
| Ограниченный бюджет | Не допускается превышение утвержденного бюджета проекта. |
| Ограниченные сроки | Основной этап внедрения должен быть завершен в течение 12 месяцев. |
| Непрерывность бизнеса | Магазины и интернет-магазин должны продолжать работу во время внедрения. |
| Зависимость от ERP | ERP не может быть заменена в рамках проекта. |
| Рост нагрузки | Ожидается увеличение количества онлайн-заказов на 20 % ежегодно. |

# 13. Задания студентам

Используя данные настоящего документа, необходимо:

1. Подготовить технико-экономическое обоснование проекта.
2. Выполнить расчет совокупной стоимости владения (TCO).
3. Рассчитать экономический эффект от предлагаемых архитектурных решений.
4. Оценить срок окупаемости проекта.
5. Подготовить прогноз изменения эксплуатационных затрат.
6. Сформировать реестр проектных рисков.
7. Выполнить качественную оценку вероятности и влияния рисков.
8. Подготовить дорожную карту внедрения с учетом имеющихся ограничений.
