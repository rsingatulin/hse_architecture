# Документ 14. Шаблоны архитектурных артефактов проекта RetailMax

## 1. Назначение документа

Настоящий документ определяет единый набор шаблонов архитектурных артефактов, которые должны использоваться проектными командами при выполнении сквозного архитектурного проекта по трансформации корпоративной информационной системы RetailMax.

Документ предназначен для:

- организации работы архитектурных команд;
- обеспечения единообразия проектной документации;
- формирования архитектурного репозитория;
- обеспечения трассируемости архитектурных решений;
- подготовки материалов для архитектурного комитета.

Все создаваемые артефакты должны быть связаны между собой:

```
Бизнес-цель
      ↓
Архитектурное требование
      ↓
Бизнес-процесс
      ↓
Информационная система
      ↓
Сервис
      ↓
Технологический компонент
      ↓
Архитектурное решение
```

# 3. Требования к оформлению архитектурных документов

Каждый архитектурный артефакт должен содержать:

| Поле | Описание |
|-|-|
| Название | Наименование документа |
| Идентификатор | Уникальный номер |
| Версия | Версия документа |
| Автор | Ответственный студент/группа |
| Дата создания | Дата подготовки |
| Статус | Черновик / На согласовании / Утвержден |
| Связанные документы | Требования, модели, ADR |

Пример имени файла:

```
REQ-001-order-processing.md

ADR-002-api-gateway.md

C4-container-retailmax-v1.puml

BPMN-sales-process-v2.drawio
```
