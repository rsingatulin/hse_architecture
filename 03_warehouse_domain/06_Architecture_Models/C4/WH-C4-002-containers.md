| ID | Контейнер | Данные / размещение |
|---|---|---|
| C1 | Интерфейс WMS | Штатный клиент/ТСД; не второй мастер |
| **C2** | **Приложение WMS** | Выбрано для UML Component/Sequence; поддерживаемые модули поставщика |
| C3 | БД WMS | Stock/Reserve/Task/Transfer/Inbox/Outbox/Audit в поддерживаемой транзакционной границе |
| C4 | Warehouse Adapter в IS-07 | API, consumer/publisher и сопоставление данных; без собственного Stock |
| C5 | Техническое состояние адаптера в IS-07 | Курсоры/доставка/карантин; не замена бизнес-идемпотентности C2 |
| C6 | Store Inventory | Служба логистики в магазине; локальные операции и синхронизация |
| C7 | Журнал магазина | Первичные движения, pending/outbox, оперативная копия; устойчивое хранилище |

WMS/ERP и их БД сохраняются на поддерживаемой инфраструктуре. Новые stateless-адаптеры размещаются на общем контейнерном контуре; Store Inventory должен переживать отсутствие WAN. Контейнер в модели C4 — приложение или хранилище, а не требование Docker для каждого блока.

Адаптеры относятся к общей IS-07; это уточняет октябрьскую схему, в которой адаптер был внутри рамки Warehouse System. Владение кодом/семантикой Warehouse не означает отдельную интеграционную платформу. Персональные исполнители и фактический стек определяются до реализации.

Исходники: [DSL](workspace.dsl), [PlantUML](WH-C4-002-containers.puml). [Детализация C2](../UML/WH-UML-001-components.md). Сетевая топология и HA — отдельная технологическая архитектура.
