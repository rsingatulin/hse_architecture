## Соответствие операций

В таблице сопоставлены операции двух BPMN As-Is и элементы ArchiMate. Названия на схемах ArchiMate короче: "Разместить товар" соответствует ручному размещению, "Собрать заказ" подбору без оптимизации маршрута. Порядок операций сохранён.

| BPMN-файл / ID элемента | Операция BPMN | Элемент ArchiMate | Поддержка приложения / данные |
| --- | --- | --- | --- |
| receiving / `WH-BPMN-ASIS-receiving_start` | Товар прибыл | Товар прибыл | Начало приёмки поставки |
| receiving / `WH-BPMN-ASIS-receiving_accept` | Принять товар | 1. Принять товар | Исполнитель: распределительный склад; чтение сведений о закупке D-05 |
| receiving / `WH-BPMN-ASIS-receiving_check` | Проверить комплектность | 2. Проверить комплектность | Исполнитель: распределительный склад; чтение сведений о товаре D-01 |
| receiving / `WH-BPMN-ASIS-receiving_place` | Разместить вручную | 3. Разместить товар | Ручное размещение сотрудником склада |
| receiving / `WH-BPMN-ASIS-receiving_record` | Обновить информацию WMS | 4. Обновить информацию WMS | Функция "Ведение остатков"; изменение бизнес-объекта D-06 |
| receiving / `WH-BPMN-ASIS-receiving_end` | Товар на хранении | Товар на хранении | Завершение приёмки и размещения |
| fulfillment / `WH-BPMN-ASIS-fulfillment_start` | Заказ поступил | Заказ поступил | Независимое начало исполнения заказа |
| fulfillment / `WH-BPMN-ASIS-fulfillment_task` | Сформировать задание | 1. Сформировать задание | Функция "Учёт заданий на комплектацию"; чтение D-03, создание складского задания |
| fulfillment / `WH-BPMN-ASIS-fulfillment_pick` | Собрать без оптимизации маршрута | 2. Собрать заказ | Исполнитель: распределительный склад; чтение складского задания |
| fulfillment / `WH-BPMN-ASIS-fulfillment_pack` | Упаковать заказ | 3. Упаковать заказ | Ручная операция сотрудника склада |
| fulfillment / `WH-BPMN-ASIS-fulfillment_handover` | Передать магазину / доставке | 4. Передать магазину / доставке | Ручная передача; дальнейшие действия получателя за границей модели |
| fulfillment / `WH-BPMN-ASIS-fulfillment_erp` | Передать изменение запасов ERP | 5. Передать изменение запасов ERP | Функция "Обмен складскими данными с ERP"; чтение D-06 |
| fulfillment / `WH-BPMN-ASIS-fulfillment_end` | Исполнение завершено | Исполнение завершено | Завершение исполнения заказа |

Файлы: [receiving.bpmn](../BPMN/WH-BPMN-ASIS-receiving.bpmn), [fulfillment.bpmn](../BPMN/WH-BPMN-ASIS-fulfillment.bpmn). Пояснения по дорожкам, типам задач и сообщениям приведены в [описании BPMN As-Is](../BPMN/WH-BPMN-001-as-is.md).

В BPMN ручные действия выполняет кладовщик / комплектовщик. На подробных схемах ArchiMate исполнителем указан распределительный склад. На обзоре BP-03 внутри подразделения выделена роль кладовщика / комплектовщика.

Поступление поставки не запускает исполнение конкретного заказа. Приёмка и комплектация имеют отдельные события начала. Инвентаризация входит в BP-03, но в этих двух BPMN не детализирована.

## Связь требований с текущей архитектурой

Ниже указано, какие операции и системы As-Is затрагивают требования Warehouse. Таблица используется при подготовке To-Be. Выполнение целевых требований действующими системами по этим схемам не проверялось.

| Требование | Текущий процесс / проблема | Элементы приложений и технологий | Текущее состояние |
| --- | --- | --- | --- |
| WH-R-04 - регистрация складских операций и инвентаризация | Приёмка, размещение, обновление WMS; отдельная инвентаризация | IS-05 WMS, SRV-05, "Ведение остатков", "Учёт инвентаризации", D-06; APP-04, DB-01 | Результат приёмки отражается в WMS. Текущий регламент инвентаризации подробно не описан |
| WH-R-05 - управляемое исполнение задания | Формирование задания, подбор, упаковка, передача | "Учёт заданий на комплектацию", D-03, складское задание; IS-05 / APP-04 | По заказу формируется задание для сотрудника склада |
| WH-R-06 - оптимизация размещения и маршрутов | Размещение вручную; подбор без оптимизации маршрута | "Разместить товар", "Собрать заказ", существующая WMS | Размещение выполняется вручную, маршрут подбора не оптимизируется |
| WH-R-02/09 - согласованность и надёжность обмена | Передача изменения запасов ERP | "Обмен складскими данными с ERP", потоки ERP и WMS, IS-07 / APP-06 | ERP и WMS обмениваются заданиями и результатами. Фактический маршрут и обработку повторов нужно уточнить |
| WH-R-10/11 - доступность и восстановление | Зависимость операций от приложений и связи | Рабочее место, выделенный канал, корпоративная сеть, APP-04, APP-01, DB-01, BACKUP-01 | Копирование ежедневное, проверка восстановления нерегулярная. Достижение целевых SLA, RTO и RPO не подтверждено |
| WH-R-15 - диагностика и наблюдаемость | Эксплуатация серверов | "Контроль серверов", APP-04, APP-01, APP-06, DB-01 | Ресурсы серверов контролируются средствами ОС. Централизованного мониторинга приложений нет |

[Каталог требований Warehouse](../../01_Business_Architecture/Requirements/WH-REQ-001-requirements.md), [Паспорт BP-03](../../01_Business_Architecture/Business_Process/WH-BP-001-process.md).
