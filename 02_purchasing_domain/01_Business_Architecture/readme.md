# Каталог архитектурных требований: Домен «Закупки товаров»

---

## Область применения

**Входит:**
- Бизнес-процесс BP-02 «Закупка товаров»
- ИС: ERP, WMS, Integration Platform, CRM
- Данные: товары, поставщики, заказы, остатки, документы закупок
- Интеграции между ERP, WMS, Integration Platform и поставщиками

**Не входит:**
- Процессы продаж, склада, интернет-продаж
- Разработка ПО, изменение оргструктуры, миграция данных

## Нефункциональные требования

### Производительность
- Время формирования прогноза: ≤15 минут
- Время ответа API Integration Platform: ≤500 мс
- Обновление остатков WMS → ERP: ≤5 минут
- Авто-согласование заказа: ≤1 минуты

### Доступность
- ERP, WMS, Integration Platform: 99,5%

### Интеграции
- Централизация через Integration Platform
- Event-Driven архитектура
- Версионирование контрактов
- Централизованный мониторинг
