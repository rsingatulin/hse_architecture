### Сервис интеграции с поставщиками (Supplier Integration Service)

**Назначение**

Техническое и процессное взаимодействие с внешними системами поставщиков (API, порталы). Трансляция внутренних моделей заказов во внешние форматы и обратно.

**Владелец сервиса**

ИТ-отдел (Архитектор интеграций) при бизнес-владении Отдела закупок.

**Ответственность сервиса**

Сервис отвечает за:
* Маршрутизацию и доставку сообщений внешним поставщикам.
* Конвертацию (маппинг) внутренних форматов данных в внешние (XML, JSON).
* Управление сессиями и журналирование обменов.

**Используемые данные**
| Объект данных | Операции |
|---|---|
| API-запрос | Create, Read |
| Маппинг данных | Read |
| Лог обмена | Create, Read |

**API**
| Метод | Назначение |
|---|---|
| `POST /api/v1/integration/send-order` | Отправка заказа поставщику во внешнюю систему |
| `GET /api/v1/integration/logs/{correlationId}` | Получение логов и статусов доставки для отладки |

**Потребители сервиса**
| Система | Назначение |
|---|---|
| Сервис управления заказами | Отправка команды на передачу заказа поставщику |
| Внешние системы поставщиков | Получение заказов и отправка подтверждений (через API Gateway) |

**Нефункциональные характеристики**
| Параметр | Значение |
|---|---|
| Доступность | 99,9% (критично для бесперебойного обмена с контрагентами) |
| Производительность | Обработка транзакции не более 200 мс (без учета времени ответа внешней системы) |
| Масштабирование | Горизонтальное (особенно для обработки очередей сообщений) |
