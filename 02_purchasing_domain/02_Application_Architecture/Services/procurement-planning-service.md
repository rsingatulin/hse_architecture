### Сервис планирования и прогнозирования (Procurement Planning Service)

**Назначение**

Анализ потребностей, расчет точек заказа и формирование планов закупок на основе прогнозов спроса, сезонности и текущих остатков.

**Владелец сервиса**

Отдел закупок (Аналитик / Менеджер по закупкам).

**Ответственность сервиса**

Сервис отвечает за:

* Расчет потребности в товарах на основе алгоритмов прогнозирования.
* Формирование рекомендаций к закупке (автоматическое создание черновиков заказов).
* Управление параметрами планирования (мин/макс запас, страховой запас).

**Используемые данные**
| Объект данных | Операции |
|---|---|
| Потребность в закупке | Create, Read, Update |
| Прогноз спроса | Read |
| Параметры планирования | Read, Update |

**API**
| Метод | Назначение |
|---|---|
| `POST /api/v1/planning/calculate-demand` | Запуск фоновой задачи расчета потребности |
| `GET /api/v1/planning/recommendations` | Получение списка сформированных рекомендаций к закупке |
| `PUT /api/v1/planning/parameters/{sku}` | Обновление параметров планирования для товара |

**Потребители сервиса**
| Система | Назначение |
|---|---|
| Сервис управления заказами | Получение сформированной потребности для конвертации в реальный заказ |
| WMS | Получение прогнозов загрузки склада |
| BI / DWH | Анализ точности прогнозных моделей |

**Нефункциональные характеристики**
| Параметр | Значение |
|---|---|
| Доступность | 99,0% (работает преимущественно в фоновом/пакетном режиме) |
| Производительность | Расчет потребности: выполнение в заданное окно обслуживания (до 1 мин) |
| Масштабирование | Вертикальное/Горизонтальное (для тяжелых вычислительных задач и ML-моделей) |
