### Сервис управления заказами поставщикам (Purchase Order Management Service)

**Назначение**

Преобразование плана закупок в конкретные заказы, внутреннее согласование, отправка поставщику и отслеживание жизненного цикла заказа до его закрытия.

**Владелец сервиса**

Отдел закупок (Менеджер по закупкам).

**Ответственность сервиса**

Сервис отвечает за:
* Создание и согласование заказов поставщикам (D-05).
* Отслеживание статусов заказа (Создан, Согласован, Отправлен, Подтвержден, Закрыт).
* Управление строками заказа и спецификациями.

**Используемые данные**
| Объект данных | Операции |
|---|---|
| Закупка / Заказ поставщику (D-05) | Create, Read, Update |
| Строка заказа | Create, Read, Update |

**API**
| Метод | Назначение |
|---|---|
| `POST /api/v1/purchase-orders` | Создание нового заказа поставщику |
| `GET /api/v1/purchase-orders/{id}` | Получение детальной информации по заказу |
| `POST /api/v1/purchase-orders/{id}/approve` | Внутреннее согласование заказа |
| `PUT /api/v1/purchase-orders/{id}/status` | Обновление статуса заказа |

**Потребители сервиса**
| Система | Назначение |
|---|---|
| Сервис интеграции с поставщиками | Получение команды на отправку заказа во внешние системы |
| WMS | Получение плановых данных о поставках для подготовки к приемке |
| ERP / Финансы | Получение данных для согласования и проведения оплаты |

**Нефункциональные характеристики**
| Параметр | Значение |
|---|---|
| Доступность | 99,9% (критичный сервис для обеспечения товарного наполнения) |
| Производительность | Время ответа критичных API не более 500 мс |
| Масштабирование | Горизонтальное (автоматическое масштабирование под нагрузку) |
