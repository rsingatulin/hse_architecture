### Сервис управления поставщиками (Supplier Management Service)

**Назначение**

Ведение единого справочника контрагентов, управление договорами, условиями поставки и рейтингами надежности поставщиков.

**Владелец сервиса**

Отдел закупок (Руководитель отдела закупок).

**Ответственность сервиса**

Сервис отвечает за:
* Создание, верификацию и классификацию поставщиков.
* Ведение истории взаимодействий и условий договоров.
* Управление рейтингами надежности и «черным списком».
* Предоставление актуальных данных о поставщиках другим сервисам.

**Используемые данные**
| Объект данных | Операции |
|---|---|
| Поставщик (D-04) | Create, Read, Update |
| Договор | Create, Read, Update |
| Рейтинг надежности | Read, Update |

**API**
| Метод | Назначение |
|---|---|
| `GET /api/v1/suppliers` | Получение списка поставщиков с фильтрацией |
| `POST /api/v1/suppliers` | Создание нового поставщика |
| `PUT /api/v1/suppliers/{id}` | Обновление данных или условий договора |
| `GET /api/v1/suppliers/{id}/rating` | Получение актуального рейтинга надежности |

**Потребители сервиса**
| Система | Назначение |
|---|---|
| Сервис управления заказами | Валидация поставщика и подтягивание условий при создании заказа |
| ERP | Синхронизация справочника контрагентов для финансового учета |
| BI / DWH | Анализ надежности и эффективности поставщиков |

**Нефункциональные характеристики**
| Параметр | Значение |
|---|---|
| Доступность | 99,5% (согласно требованиям к внутренним системам, DOC-17) |
| Производительность | Время ответа API не более 200 мс |
| Масштабирование | Горизонтальное (нагрузка относительно низкая, но справочник может расти) |
