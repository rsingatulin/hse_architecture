# Архитектурное проектирование блока «Продажи» (BP-01)

**Целевая система:** POS (IS-04)  
**Контекст:** Оффлайн-продажи в розничных магазинах RetailMax.

## 1. Домены и субдомены

| Субдомен | Тип | Обоснование |
| --- | --- | --- |
| Розничная продажа (оформление чека) | Core | Непосредственно генерирует выручку и определяет клиентский опыт на кассе. |
| Ценообразование и акции | Core | Коммерческая дифференциация; в As-Is правила акций рассогласованы между каналами. |
| Клиенты и лояльность | Supporting | Поддерживает удержание; владелец — маркетинг (BP-05). |
| Каталог товаров | Supporting | Мастер-данные товара (источник — ERP). |
| Доступность остатков | Supporting | Списание остатков и проверка наличия. |
| Оплата (эквайринг) | Generic | Поставщик внешней услуги. |
| Фискализация | Generic | Регулируемая функция (ФР, ОФД). |
| Аутентификация кассиров (SSO) | Generic | Сквозная корпоративная функция (SA-01). |

## 2. Bounded Contexts 

| Bounded Context | Ключевые сущности модели | Владелец |
| --- | --- | --- |
| Продажа (Checkout) | Корзина, Позиция чека, Продажа, Чек | POS / Коммерческий департамент |
| Цены и акции | Цена, Акция, Правило скидки | Коммерческий департамент |
| Клиент и лояльность | Клиент, Бонусный счет, Бонусная операция | Маркетинг / CRM |
| Каталог товаров | Товар, Категория, Характеристика, Артикул | Коммерческий департамент / ERP |
| Запасы | Остаток, Резерв, Доступно | Логистика / WMS |
| Оплата | Платеж, Транзакция, Способ оплаты | Generic (эквайринг) |
| Фискализация | Фискальный документ | Generic (ФР/ОФД) |

## 3. Каталог сервисов

### 3.1. Сервисы целевой системы POS (Внутренние)

| Сервис | Bounded Context | Ответственность (бизнес-функция) | Данные | Зависимости |
|---|---|---|---|---|
| Checkout Service | Продажа | Жизненный цикл чека: корзина, сканирование, применение скидок, закрытие продажи. | Корзина, Продажа (D-07) | Pricing, Loyalty, Payment, Fiscal |
| Payment Service | Оплата | Оркестрация оплат и статусы транзакций. | Платеж, Транзакция | Терминал эквайринга |
| Fiscal Service | Фискализация | Формирование и передача фискального чека. | Фискальный документ | Фискальный регистратор |
| Local Cache Service | Каталог / Лояльность | Локальный кэш товаров, цен и карт для работы кассы при потере связи (REQ-BR-02). | Товар, Цена, Клиент (кэш) | Синхронизация с Catalog, Pricing, Loyalty |
| Outbox Service | Продажа (интеграция) | Гарантированная доставка продаж в ERP/CRM/BI, повторная отправка при сбое (INT-01). | Продажа, события | Integration Platform |
| Recommendation Service | Продажа | AI-рекомендации сопутствующих товаров на кассе (AI-01). | Корзина, Продажа | AI-сервис персонализации |

### 3.2. Внешние сервисы, потребляемые POS

| Сервис | Bounded Context | Владелец | Назначение для POS |
|---|---|---|---|
| Product Catalog Service | Каталог товаров | Коммерческий департамент | Товары и характеристики. |
| Pricing & Promotion Service | Цены и акции | Коммерческий департамент | Единые цены и правила акций для всех каналов. |
| Loyalty Service | Клиент и лояльность | Маркетинг / CRM | Бонусы и персональные скидки. |
| Inventory Service | Запасы | Логистика / WMS | Прием события для списания остатков. |
| Identity Service (SSO) | Аутентификация | ИТ-подразделение | Аутентификация кассиров. |
