# ADR-002 Использование ИИ и адаптация технической архитектуры
| Поле | Значение |
|---|---|
| **Идентификатор** | ADR-002 |
| **Наименование** | Обеспечить использование ИИ и адаптировать техническую архитектуру с учетом принятого решения ADR-001 |
| **Решение** | Использование технологий искусственого интеллекта считать нецелесообразным и оставить техническую архитектуру без изменений  |
| **Причина** | 1. Бизнес-процесс офлайн-продаж выполняется с достаточной скоростью и качеством, внедрение технологии ИИ к отдельным операциям не оказывает существенного бизнес/экономического эффекта;<br>2. Установка локальной базы данных не влияет на техническую архитектуру |
| **Статус** | Принято |
| **Дата принятия решения** | 18.11.2026 |
