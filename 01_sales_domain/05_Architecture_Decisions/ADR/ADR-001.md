# ADR-001 Синхронизация данных системы POS
| Поле | Значение |
|---|---|
| **Идентификатор** | ADR-001 |
| **Наименование** | Обеспечить синхронизацию данных (в части персональных скидок) и их периодическую подгрузку |
| **Решение** | Внедрение локального слоя в магазинах |
| **Причина** | 1. Уменьшение зависимости от центральных сервисов;<br>2. Уменьшение времени задержки получения информации о бонусах |
| **Статус** | Принято |
| **Дата принятия решения** | 14.10.2026 |
