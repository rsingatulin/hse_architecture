# UML Sequence Diagrams — Retention Domain

## Назначение

Диаграммы последовательности показывают поведение компонентов домена во времени
для ключевых сценариев. Вместе с BPMN (`04_1_bpmn`), ArchiMate (`04_2_archimate`)
и C4 (`04_3_c4`) образуют цепочку проектирования: от архитектуры предприятия
до взаимодействия приложений во времени.

## Сценарии

| ID | Файл | Сценарий | Источники |
|---|---|---|---|
| SEQ-01 | `seq_01_purchase_to_offer.puml` | Покупка на кассе → обновление метрик → персональное предложение | BPMN `retention.bpmn` (основной поток), C4 Container As-Is |
| SEQ-02 | `seq_02_online_purchase.puml` | Онлайн-покупка: лояльность, заказ, обновление метрик, триггерная коммуникация | C4 Context (Интернет-магазин, ERP), C4 Container As-Is |
| SEQ-03 | `seq_03_pos_loyalty_request.puml` | Синхронный запрос баланса бонусов и предложений на кассе | C4 Context («Запрос баланса бонусов…»), C4 Container As-Is |
| SEQ-04 | `seq_04_batch_etl.puml` | Пакетная ETL-загрузка и обновление витрин (As-Is, nightly) | ArchiMate R-21…R-27, PRB-01/PRB-02 (`problems.md`) |
| SEQ-05 | `seq_05_trigger_message.puml` | Отправка триггерного маркетингового сообщения | C4 Context («Отправка триггерных маркетинговых сообщений») |

## Участники

Наименования участников соответствуют C4 Container Diagram As-Is
(`04_3_c4/Container_Diagram_AsIs_Retetion.PNG`): Интеграционная платформа, CRM,
BI-система, БД CRM, БД BI; внешние системы: POS, Интернет-магазин, ERP,
Каналы коммуникаций.

## Допущения

- техническая спецификация текущих ETL-маршрутов (частота, окно загрузки)
  в репозитории отсутствует — SEQ-04 отражает пакетный режим по ArchiMate
  «Ограничения As-Is» и PRB-01;
- обработка согласий на коммуникацию (SEQ-05) показана как проверка в CRM,
  отдельный consent-сервис в As-Is не выделен.
