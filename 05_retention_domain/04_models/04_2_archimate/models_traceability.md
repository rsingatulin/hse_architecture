# Трассировка моделей Retention

Матрица связывает существующие модели через идентификаторы ArchiMate. Она
показывает, какие элементы BPMN и C4 представляют одни и те же процессы,
системы и данные.

| ArchiMate | BPMN | C4 | Смысл связи |
|---|---|---|---|
| B-01 Клиент | StartEvent: «Совершение покупки»; Activity: «Сообщение клиенту о предложении» | Person: «Клиент» | Клиент инициирует покупку и получает предложение |
| B-02 Кассир | Lane: «Канал продаж»; Activity: «Проведение чека» | Person: «Кассир» | Кассир участвует в розничном обслуживании |
| B-03 Маркетолог / аналитик | Activities: «Пересчет метрик», «Формирование персонального предложения» | Person: «Маркетолог / Аналитик» | Бизнес-пользователь анализирует данные и управляет кампаниями |
| B-04 Покупка и обслуживание клиента | StartEvent → «Фиксация покупки» → «Проведение чека» | External systems: POS, Интернет-магазин | Операционный процесс покупки |
| B-05 Подготовка маркетинговой аналитики | «Передача данных о покупке» → «Обновление аналитических витрин» → «Пересчет метрик» | Container: BI-приложение | Подготовка и расчёт аналитики |
| B-06 Программа лояльности | «Сохранение метрик в профиль клиента»; «Формирование персонального предложения» | Container: Сервис лояльности | Управление профилем, бонусами и правилами |
| B-07 Маркетинговая аналитика | «Обновление аналитических витрин»; «Пересчет метрик» | Container: BI-приложение | Подготовка витрин, метрик и отчётности |
| A-01 POS | Lane: «Канал продаж»; «Фиксация покупки»; «Проведение чека» | External system: Point Of Sale | Розничный источник операций |
| A-02 Интернет-магазин | Lane: «Канал продаж» | External system: Интернет-магазин | Онлайн-канал и источник заказов |
| A-03 CRM | Lane: «CRM»; «Формирование персонального предложения» | Container: База профилей клиентов | Профили, бонусы и персональные предложения |
| A-04 ERP | Data store: «База покупок» | External system: ERP | Источник заказов, товаров и транзакций |
| A-05 BI-система | Lane: «BI-система»; «Обновление аналитических витрин» | Container: BI-приложение | Витрины и аналитические метрики |
| A-06 Интеграционные ETL-процессы | «Передача данных о покупке» | API Gateway / связи с внешними системами | Передача данных между источниками и аналитикой |
| D-01 Профиль клиента | Data store: «База профилей клиента» | База профилей клиентов | Единый объект сопоставления клиента |
| D-02 Бонусный счёт | «Сохранение метрик в профиль клиента» | База профилей клиентов | Баланс и операции лояльности |
| D-03 Данные покупки / заказа | Data object: «Данные о покупке»; «База покупок» | POS, Интернет-магазин, ERP | Факты продаж и заказов |
| D-04 Аналитические метрики | Data store: «База метрик» | Хранилище данных; BI-приложение | Метрики и результаты аналитической обработки |
| D-05 BI-хранилище / аналитические витрины | Data store: «База метрик»; «База покупок» | Хранилище данных | Текущее аналитическое хранение; отдельный корпоративный DWH не утверждается |

Дополнительное отношение модели: `B-05 Подготовка маркетинговой аналитики
--Realization--> B-07 Маркетинговая аналитика`.

## Границы интерпретации

Существующий BPMN-файл содержит элементы целевого поведения, например
персональное предложение и подключение ИИ. В этой матрице они сопоставлены с
бизнес-процессами As-Is как фактически моделируемые шаги домена, но это не
означает, что соответствующие отдельные сервисы уже существуют. Целевые
компоненты C4 — Kafka, MDM и отдельный сервис ИИ — не включены в ArchiMate
As-Is.
